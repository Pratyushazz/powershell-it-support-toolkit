# Sample configuration profile design (illustrative)

- Name: LAB-Windows-Security-Baseline-Demo
- Scope: dedicated lab test group only
- Purpose: demonstrate policy assignment and settings validation
- Settings: choose non-disruptive supported settings from Settings Catalog
- Rollback: remove assignment and sync; verify settings revert where supported
- Validation: record device status, errors and redacted proof

Not an importable profile or production baseline.
