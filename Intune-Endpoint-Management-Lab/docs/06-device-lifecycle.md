# Scenario 6: Device lifecycle

- **Enroll:** provision and register device under approved workflow.
- **Manage:** configuration, compliance, app deployment and monitoring.
- **Troubleshoot:** sync, policy status, logs, connectivity and user context.
- **Retire:** remove management relationship as appropriate when leaving service.
- **Wipe:** destructive action; only on disposable test devices with explicit safeguards.
- **Delete:** remove inventory record; understand that deleting a record is not necessarily the same as wiping the device.

Before destructive tests: confirm disposable device, backups, authorization and consequences; record results. Never test on real employer or user devices.
