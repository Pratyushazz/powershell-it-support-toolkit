# Scenario 5: Windows update rings

## Planning example
- Pilot ring: small test group, shorter deferrals.
- Broad ring: wider deployment only after pilot validation.
- Define active hours, deadlines and restart behavior carefully.

## Checklist
- [ ] Review supported update settings.
- [ ] Create a test ring.
- [ ] Assign to test device.
- [ ] Verify assignment and update reporting.
- [ ] Document impact and restart behavior.
- [ ] Expand only after approval and validation.

Avoid testing forced restart or disruptive settings on your primary device.
