# Scenario 1: Windows device enrollment

## Goal
Understand the prerequisites and workflow for a test Windows endpoint.

## Checklist
- [ ] Confirm tenant and test-user licensing and enrollment permissions.
- [ ] Review enrollment restrictions and platform limits.
- [ ] Choose a supported enrollment method for the lab.
- [ ] Enroll a disposable test device.
- [ ] Confirm device appears in Intune device inventory.
- [ ] Record enrollment date, OS/build, ownership, method and sync status (redact identifiers).
- [ ] Trigger a sync and verify check-in.

## Troubleshooting prompts
Is the user licensed? Is enrollment allowed? Are network, proxy and time settings correct? Is the device already registered/enrolled? Review relevant Windows and Intune troubleshooting logs.

Use redacted screenshots only. Never publish serial numbers, device IDs, tenant IDs, usernames or organization data.
