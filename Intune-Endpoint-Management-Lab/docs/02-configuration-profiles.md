# Scenario 2: Configuration profiles

## Example baseline (design only)
| Setting | Lab intent | Validation |
|---|---|---|
| Screen lock | Require secure sign-in after idle period | Confirm test device setting |
| Firewall | Keep Windows firewall enabled | Verify status locally |
| Browser | Demonstrate profile targeting concepts | Confirm settings and conflicts |
| Device restrictions | Document non-disruptive settings | Verify effective configuration |

## Workflow
1. Create a test group and profile.
2. Select platform and settings catalog.
3. Assign only to the test group.
4. Check assignment status and device sync.
5. Validate locally and document conflicts or errors.
6. Roll back the test profile if needed.

This is a practice guide, not a prescriptive enterprise security baseline.
