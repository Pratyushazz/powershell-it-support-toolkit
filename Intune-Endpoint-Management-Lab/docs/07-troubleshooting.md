# Troubleshooting playbook

| Symptom | Check |
|---|---|
| Device not appearing | Enrollment prerequisites, license, restrictions, enrollment status |
| Policy pending | Device sync, assignment scope, check-in time |
| Policy conflict/error | Conflicting profiles, supported settings, error code |
| App install failed | Installer, detection/requirements, install context, logs |
| Compliance not updating | Policy assignment, sync, device state, reporting delay |
| Update status unclear | Update policy assignment, Windows version, reporting and logs |

Ticket note: issue, affected device (redacted), impact, checks, findings, action, validation and escalation.
