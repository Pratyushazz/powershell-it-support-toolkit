# Scenario 3: Compliance policy

## Example Windows compliance concepts
- Minimum OS version (select a version appropriate for test devices).
- Password / device security requirements.
- Firewall and antivirus state.
- Device health and reporting.

## Test plan
- [ ] Configure a test policy.
- [ ] Assign only to the lab group.
- [ ] Review device compliance status.
- [ ] Use a safe, reversible test setting only for non-compliance testing.
- [ ] Document status and user/device impact.
- [ ] Restore the device and confirm compliant status.

Conditional Access integration is optional and should be tested in an isolated, carefully planned tenant to avoid lockout.
