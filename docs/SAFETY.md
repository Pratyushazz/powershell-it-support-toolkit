# Safety and privacy

- Use scripts only on devices you own or are authorized to support.
- These scripts are intended to be read-only. Review code before execution.
- Do not upload real machine output, usernames, serial numbers, IP addresses, logs, software lists, or corporate details to a public repository.
- Use synthetic examples or redact outputs before publishing.
- Never commit credentials, tokens, certificates, private keys, or secrets.
- Follow employer policies and approved change/security processes.
