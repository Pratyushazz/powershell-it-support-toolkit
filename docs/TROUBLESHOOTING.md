# Troubleshooting the toolkit

| Issue | Possible reason | Suggested action |
|---|---|---|
| Access denied | Permissions or restricted log access | Run only if authorized; request approved access |
| Script blocked | Execution policy or security control | Follow organization policy; do not bypass it |
| No results | Time range, filter or log availability | Adjust parameters and validate manually |
| Network check fails | DNS, proxy, firewall, target or connectivity | Test another approved target and compare |
| Update history unavailable | API or platform limitations | Validate using Windows Settings or approved management tools |
| Different output on PS7 | Cmdlet/API compatibility | Check Windows version and PowerShell version |
