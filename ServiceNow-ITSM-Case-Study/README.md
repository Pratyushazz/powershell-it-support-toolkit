# ServiceNow ITSM Case Study — Service Desk Portfolio

A standalone portfolio project with **fictional, realistic IT Service Desk incidents** demonstrating ticket intake, categorization, impact/urgency prioritization, L1 troubleshooting, escalation, communication and closure. These are simulated case studies, not actual company tickets or live ServiceNow screenshots.

![Incident workflow](images/incident-lifecycle.svg)

## Scenarios
1. VPN connectivity issue (P3)
2. Outlook send issue (P2)
3. Account lockout (P3)
4. Printer queue (P3)
5. Slow laptop (P3)
6. MFA registration (P2)
7. Windows Update failure (P3)
8. Shared application outage / major incident (P1)

Priority labels are illustrative only; actual priority and SLA definitions depend on an organization's policy.

## Workflow
Log → Categorize → Assess impact/urgency → Prioritize → Assign → Diagnose → Escalate if needed → Resolve & validate → Close. See [incident workflow](docs/incident-workflow.md) and [priority guide](docs/priority-and-sla.md).

## Authenticity / safety
All users, IDs, events, symptoms, metrics and resolutions in this project are fictional. No real ServiceNow instance was used. Do not represent these as live screenshots or actual production experience. Recreate selected scenarios in an authorized test instance if you want to add genuine, sanitized screenshots.
