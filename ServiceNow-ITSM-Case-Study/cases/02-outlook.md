# Case 02 — Outlook send failure
**Example ID:** INC1001002 | **Priority:** P2 | **Category:** Application / Email

**Symptom:** Messages remain in Outbox, but incoming mail works.
**L1 checks:** Test webmail, Outlook status, message size, connectivity, safe mode/add-in checks.
**Escalation:** Simulated L2 review of client/add-in logs.
**Fictional resolution:** Problematic add-in disabled with approval; test send/receive succeeded.
