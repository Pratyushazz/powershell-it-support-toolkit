# Case 05 — Slow laptop
**Example ID:** INC1001005 | **Priority:** P3 | **Category:** Endpoint / Performance

**Symptom:** Slow startup and lag in meetings.
**L1 checks:** Recent changes, Task Manager, disk space, startup apps, updates and event logs.
**Fictional resolution:** Unneeded startup app disabled with approval; reboot and performance checks successful.
**Escalate:** Recurring crashes, hardware concern or security alert.
