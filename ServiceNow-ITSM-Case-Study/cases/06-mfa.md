# Case 06 — MFA challenge failure
**Example ID:** INC1001006 | **Priority:** P2 | **Category:** Identity / Authentication

**Symptom:** MFA fails after phone replacement.
**L1 checks:** Identity verification, exact error, time/device and scope.
**Escalation:** Identity admin performs secure re-registration and reviews sign-in logs.
**Fictional resolution:** Authorized re-registration completed; user test sign-in succeeded.
**Security:** Never casually bypass MFA or share recovery codes.
