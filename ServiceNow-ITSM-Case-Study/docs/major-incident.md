# Major incident scenario

**Scenario (fictional):** A shared application becomes unavailable to several teams.

1. Service Desk confirms scope, timestamps and symptoms; link related tickets.
2. Incident lead coordinates response according to policy.
3. Technical teams investigate; Service Desk avoids duplicate troubleshooting.
4. Stakeholders receive approved updates on an agreed cadence.
5. Restoration is validated.
6. Post-incident review documents timeline, impact, confirmed cause, actions and lessons.

**Update template:** Status / impact / current action / next update time.
