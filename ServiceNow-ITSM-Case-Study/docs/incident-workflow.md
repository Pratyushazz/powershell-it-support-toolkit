# Incident workflow & ticket template

![Workflow](../images/incident-lifecycle.svg)

## Ticket fields
- Incident number (fictional)
- Caller / affected service (fictional or redacted)
- Short description and details
- Category / subcategory
- Impact, urgency, priority
- Assignment group
- Internal work notes
- User-facing comments
- Resolution notes / validation

**Sample work note:** “Confirmed issue affects one user. Tested approved alternate access path; captured error text and timestamp. Completed initial checks and escalated with sanitized evidence.”

**User update:** “Thanks for reporting this. We are investigating and completed initial checks. We will update you after the next validation step.”
